# Sistem Informasi Pengelolaan Kontrakan

## Deskripsi Proyek
Sistem Informasi Pengelolaan Kontrakan merupakan aplikasi berbasis web yang dirancang untuk membantu pemilik kontrakan dalam mengelola informasi dan aktivitas operasional kontrakan secara lebih mudah, terstruktur, dan efisien.

Aplikasi ini diharapkan dapat membantu pemilik kontrakan dalam mengelola data kamar, data penyewa, pembayaran uang sewa, serta memantau ketersediaan kamar.

## Tujuan Proyek
1. Mempermudah pengelolaan data kamar kontrakan.
2. Mempermudah pencatatan data penyewa.
3. Membantu pemilik memantau pembayaran uang sewa.
4. Menyediakan informasi ketersediaan kamar.
5. Membantu pengelolaan informasi kontrakan secara terstruktur.

## Target Pengguna
Pemilik kontrakan.

## Rencana Fitur
- Pengelolaan data kamar kontrakan.
- Pengelolaan data penyewa.
- Pencatatan pembayaran uang sewa.
- Pemantauan status pembayaran.
- Informasi ketersediaan kamar.
- Pencatatan masa sewa.
- Laporan pemasukan kontrakan.
- Pencarian data kamar dan penyewa.
- Dashboard informasi kontrakan.
- Login pemilik kontrakan.

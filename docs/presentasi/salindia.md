# Salindia Presentasi — Sistem Informasi Pengelolaan Kontrakan

Struktur: masalah → solusi → bukti → pelajaran (13 slide, ±20 menit).

| No | Slide | Pesan dan bukti |
|---|---|---|
| 1 | Judul | Nama proyek, klien, anggota |
| 2 | Masalah klien | Kesulitan mengelola kamar, penyewa, pembayaran; satu kutipan wawancara |
| 3 | Solusi dan kebutuhan | KF utama dan dua peran (pemilik, kasir) |
| 4 | Rancangan | Arsitektur tiga lapis dan ERD ringkas |
| 5 | Alur vibe coding terkendali | Enam langkah; satu siklus Terima/Ubah/Tolak |
| 6–7 | DEMO | Alur inti dua peran dengan data karangan |
| 8 | Tinjauan kode dan keamanan | Tabel temuan + satu sebelum/sesudah |
| 9 | Pengujian | 39 test case, 29 fungsi uji, 3 cacat ditemukan |
| 10 | UAT dan rilis | Hasil UAT (simulasi), skor SUS, tag v1.0.0 |
| 11 | Analisis jurnal | Proporsi keputusan, jenis galat AI, pelajaran |
| 12 | Keterbatasan dan rencana | Jujur; calon v1.1 |
| 13–14 | Kontribusi dan penutup | Peran tiap anggota; tanya jawab |

Cadangan: rekaman layar demo; data karangan; akun dua peran; jangan menampilkan
berkas konfigurasi. Bila aplikasi macet, lanjutkan dengan rekaman dan jelaskan
secara jujur.

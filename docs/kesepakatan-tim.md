# Kesepakatan Kerja Individu

## 1. Identitas
- Proyek / klien: Sistem Informasi Manajemen Kontrakan
- Anggota dan peran:
  - Nama: Bayu Nanda Pamungkas
  - Peran: Product Owner, Scrum Master, dan Developer

## 2. Komunikasi
- Kanal utama: WhatsApp dan komunikasi langsung dengan dosen.
- Waktu evaluasi pekerjaan: Setiap hari setelah kegiatan perkuliahan atau sesuai waktu luang.
- Batas waktu membalas pesan: Maksimal 1 x 24 jam untuk komunikasi terkait proyek.

## 3. Aturan Git
- Tidak melakukan perubahan langsung pada branch main setelah struktur awal dibuat.
- Semua perubahan dilakukan melalui branch dan Pull Request.
- Nama branch menggunakan format fitur-..., perbaikan-..., atau docs-....
- Setiap Pull Request ditinjau secara mandiri sebelum di-merge.
- Pesan commit harus menjelaskan isi perubahan.

## 4. Aturan Penggunaan AI
- Setiap penggunaan AI dicatat dalam Jurnal Vibe Coding.
- Tidak memasukkan data pribadi klien, kata sandi, atau kunci akses ke AI.
- Kode hasil AI harus diperiksa dan dipahami sebelum di-commit.
- AI digunakan sebagai alat bantu, bukan pengganti pemahaman dan tanggung jawab pengembang.

## 5. Definition of Done
Sebuah fitur dianggap selesai apabila:
- Memenuhi kriteria penerimaan yang telah ditentukan.
- Kode program sudah diperiksa dan diuji.
- Tidak terdapat kesalahan yang mengganggu fungsi utama.
- Perubahan sudah ditinjau melalui Pull Request.
- Jurnal Vibe Coding sudah diperbarui.
- Perubahan sudah berhasil di-merge ke branch main.

## 6. Jika Ada Masalah
- Anggota tidak aktif: Tidak berlaku karena proyek dikerjakan secara individu. Jika mengalami kendala, mencari solusi melalui dokumentasi, dosen, atau sumber belajar.
- Perbedaan pendapat: Tidak berlaku dalam kerja individu. Keputusan teknis ditentukan berdasarkan kebutuhan proyek dan arahan dosen.

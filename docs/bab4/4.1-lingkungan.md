# 4.1 Lingkungan Implementasi

Sistem Informasi Pengelolaan Kontrakan dibangun dengan tumpukan perangkat lunak
yang sederhana dan dapat dipasang ulang oleh pihak lain hanya dengan mengikuti
README. Tabel 4.1 memuat versi yang terkunci pada `requirements.txt` dan
`requirements-dev.txt`.

**Tabel 4.1 — Versi perangkat lunak**

| Komponen | Versi | Sumber |
|---|---|---|
| Python | 3.14.5 (pengembangan) | `python --version` |
| Flask | 3.1.3 | requirements.txt |
| Werkzeug | 3.1.9 | requirements.txt |
| Jinja2 | 3.1.6 | requirements.txt |
| itsdangerous | 2.2.0 | requirements.txt |

| pytest | 9.1.1 | requirements-dev.txt |
| SQLite | bawaan Python | stdlib |
| Git | 2.x | repositori |

Sistem operasi pengembangan adalah Windows 11; aplikasi juga diuji pada folder
bersih dengan virtual environment baru (uji orang asing) dan berjalan tanpa
penyesuaian. Penyimpanan data memakai SQLite pada berkas tunggal
`instance/kontrakan.db` yang lokasinya dapat diubah lewat variabel lingkungan
`KONTRAKAN_DB`.

**Asisten AI dan cara pemakaiannya.** Selama pengembangan, kelompok memakai
asisten AI untuk membuat draf kode, uji, dan dokumen. Setiap keluaran AI
ditinjau dengan daftar periksa Lampiran C Jobsheet 12 sebelum diterima;
keputusan (Terima/Ubah/Tolak) dicatat pada `jurnal-vibe-coding.md`. AI tidak
dipakai untuk menulis laporan final tanpa tinjauan, dan tidak dipakai saat
latihan tanya jawab individu.

**Konfigurasi proyek.** Kunci rahasia, nama basis data, dan mode produksi
berasal dari variabel lingkungan (`SECRET_KEY`/`FLASK_SECRET_KEY`,
`KONTRAKAN_DB`, `APP_ENV`, `COOKIE_SECURE`). Produksi tanpa kunci rahasia
menolak start dengan `RuntimeError`. Tidak ada kata sandi atau kunci rahasia
pada kode atau repositori.

# Penyesuaian Kegiatan Design Review

## Latar Belakang

Jobsheet Sesi 2 Langkah 11 mengarahkan mahasiswa untuk melaksanakan design review silang antarkelompok.

Dalam pelaksanaan proyek Sistem Informasi Pengelolaan Kontrakan, dosen mengarahkan pengerjaan proyek menggunakan metode individu. Oleh karena itu, kegiatan review silang antarkelompok tidak dapat dilaksanakan sebagaimana ketentuan awal jobsheet.

## Penyesuaian

Untuk melengkapi dokumentasi tahapan jobsheet, dilakukan simulasi design review individu dengan bantuan AI sebagai reviewer independen.

Simulasi dilakukan berdasarkan dokumen kebutuhan proyek, rancangan wireframe, anotasi antarmuka, dan rencana pengujian.

## Batasan

1. Simulasi tidak dianggap sebagai kegiatan presentasi kelompok.
2. Simulasi tidak dianggap sebagai tinjauan dari kelompok lain.
3. Masukan reviewer merupakan bahan evaluasi, bukan keputusan perubahan otomatis.
4. Keputusan penerimaan atau penolakan masukan dicatat pada tahap evaluasi berikutnya.
5. Jika dosen memberikan tinjauan langsung, hasilnya dapat ditambahkan sebagai tinjauan terpisah.
